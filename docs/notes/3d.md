## 3D viewer (owner 2026-11-10; our own viewer, models from the owner's install, never shipped)
Models: .rrgeom in DX12Geo<Civ>.sga (detailed, 60-85 KB) and Gen7AssetsGeometry.sga (all civs, ~9 KB): units are assembled
from parts - body by look + age (eng_infantry_light_age02, eng_ranged_bow_age02, eng_cavalry_armor_age03), horse
(animals/eng_horse_combined_*), weapon / shield (common/weapons, civ weapons). Unit -> parts: tools/game_assets.py artmap
(art references in the decoded ebps / sbps). Owner's choices: Gen7 models only (enough); static pose by default, a toggle
for poses / animation; flat colours with the usual player / team colouring (no game textures); instanced drawing (one
draw call per part type), only the unit types in that replay embedded once.
Export (owner's run 2026-11-10): `model-export <in.rrgeom> <out.glb>` (no -m) works but writes <index>_<name>.glb next to the
given path (0_eng_infantry_light_age02.glb, 7 KB from a 9.5 KB Gen7 file); it exits 0 even when nothing is written.
Meshes (parts_info.json, owner 2026-11-10): no skin, no transforms; y up, metres = map units, forward +z (camel neck to +2.39);
weapons / shields grip at the origin, blade up; riders come out standing on the ground (feet 0, ~1.95 tall); siege / ships
come assembled (pieces in place). Soldiers 150-250 triangles, weapons 20-60, mangonel 1,600.
Unit -> parts: art is not on the unit file; entity_blueprint_ext / weapon / tier_ext name attachment lists
(attachments\attachment_lists, now decoded by attrib) that point into art/. tools/unit_models.py -> models/unit_models.json
(1,658 units, 891 parts; body = the tier list's body for the unit's own tier, weapon = first weapon list that is not torch /
charge / spear wall / fx_, villagers and siege crew body only). game_assets.py export-parts: one batch export of the Gen7
copies -> models/parts/<name>.<mesh>.glb; parts-info -> models/parts_info.json.
Page (owner 2026-11-10: a third page; run.py / record.py --out viewer,fights,3d, default viewer,fights): viewer/build_3d.py
work/<name>.fights.json -> views/<name>.3d.html from viewer/view3d.html (three.js r128 from cdnjs). Assembly in Python: mount =
the mesh longer than 2 along z, riders lifted so half their height sits on the mount's top over its middle third, head end =
the higher end (turned if at -z); weapon at the right hand (-x extreme vertices), shields / extras at the left, tilt by weapon
name (TILT). Units without a model: plain shapes by class. Terrain = the height grid as a vertex-coloured mesh (height + slope;
cliff / water tiles from the v7 grid); trees / berries / mines / animals / relics = instanced shapes from the node snapshots;
buildings = player-coloured boxes at the footprint size (tiles; name guess without them), height by HP. Heading: movement over
+-0.3 s, else towards the target, else kept. Camera: orbit (drag), pan (right / shift drag), zoom (wheel), double-click home,
fight menu frames a fight. Not checked with real three.js here (cdnjs / npm unreachable in the dev container; logic run in
Chromium with a stub THREE): open on the owner's PC. Handedness: fixed in p43 (see the end).
